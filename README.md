## About Me

I'm **Siva Reddy**, an Assistant Manager in Data/Cloud Engineering at **LatentView Analytics**, with 8+ years of experience designing, developing, and optimizing enterprise data platforms.

My engineering work sits at the intersection of **distributed data processing, cloud-native architecture, data governance, and analytics engineering**.

I specialize in building reliable batch and streaming pipelines using Azure Databricks, Apache Spark, PySpark, SQL, Delta Lake, Azure Data Factory, and Apache Airflow.

Beyond implementation, I focus on the decisions that make data platforms sustainable: selecting the right processing patterns, improving data quality, reducing execution costs, simplifying orchestration, and designing for maintainability.

My recent work also extends into **AI-enabled analytics**, including enterprise data integration for conversational analytics and LLM-powered applications.

**My engineering principles**

- **Design for scale:** Build systems that can evolve with increasing data volume and complexity.
- **Optimize with evidence:** Diagnose bottlenecks using execution plans, Spark metrics, and workload characteristics.
- **Engineer for reliability:** Treat validation, observability, recovery, and idempotency as architectural requirements.
- **Govern by design:** Integrate security, access control, and data quality into the platform lifecycle.
- **Connect technology to outcomes:** Translate technical improvements into measurable business value.
